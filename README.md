## 1. Welcome!

The FR Legends Asset Database is the content repository
for the FR Legends Skeleton Key ecosystem.

It provides a structured home for downloadable cars,
liveries, packs, community creations, stock assets,
and official ethanlabs101 releases.

Every asset is documented and organized so it can be
identified, downloaded, and used through Skeleton Key.

Thank you for choosing FR Legends Skeleton Key!

## 4. Using Assets with Skeleton Key

The easiest way to use assets from this database is through
the FR Legends Skeleton Key Vault.

Skeleton Key provides the tools necessary to manage and
inject compatible assets into FR Legends.

### Recommended workflow

1. Install **FR Legends Skeleton Key**
2. Run the CLI
3. Navigate to the Online Asset Manager
4. Select an asset or pack
5. Download the required payload
6. Add the asset to your Vault
7. Use Skeleton Key to manage/inject the asset

**[Get Skeleton Key →](https://github.com/ethanlabs101/frlegends-skeleton-key/tree/main)**

## 5. Want to submit an asset?

All assets submitted to the database should follow the
repository's organization and documentation standards.

Asset Rules:

- no 18+ content
- no offensive content period
- no low quality work
- no copies of already added content

Submissions MUST Include:

- car.json (derived payload from skeleton key)
- author name
- asset name
- asset description (1 small sentence)
- .png, .jpeg, .jpg of the car in-game

Submit An Asset Today!

- [Telegram]()
- [Proton Mail]()

Failure to comply with asset rules will resort in all future requests ignored.
