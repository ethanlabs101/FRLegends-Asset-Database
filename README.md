## 1. Welcome!

The FR Legends Asset Database is the content repository
for the FR Legends Skeleton Key ecosystem.

It provides a structured home for downloadable cars,
liveries, packs, community creations, stock assets,
and official ethanlabs101 releases.

Every asset is documented and organized so it can be
identified, downloaded, and used through Skeleton Key.

Thank you for choosing FR Legends Skeleton Key!

## 4. Asset Information

Every asset contains its own documentation describing
what it is, who created it, its contents, compatibility,
version information, and installation information.

Depending on the asset, documentation may include:

- Asset name
- Creator
- Asset type
- Version
- Description
- Contents
- Compatibility
- Preview images
- Installation instructions
- Changelog
- Credits
- License

---

## 5. Using Assets with Skeleton Key

The easiest way to use assets from this database is through
the FR Legends Skeleton Key Vault.

Skeleton Key provides the tools necessary to manage and
inject compatible assets into FR Legends.

### Recommended workflow

1. Install **FR Legends Skeleton Key**
2. Browse the Asset Database
3. Select an asset or pack
4. Download the required payload
5. Add the asset to your Vault
6. Use Skeleton Key to manage/inject the asset

**[Get Skeleton Key →](...)**

## 9. Asset Standards

All assets submitted to the database should follow the
repository's organization and documentation standards.

Assets should include:

- Correct directory structure
- Valid asset metadata
- Accurate creator attribution
- Version information
- Compatibility information
- Appropriate documentation
- Required payload files

Do not upload modified or redistributed content without
the appropriate rights or attribution.

**[Read the Asset Standards →](...)**
